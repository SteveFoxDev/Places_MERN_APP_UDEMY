# Places

MERN stack app that diplays a 'Place' and shows it's position on a map

## About
Places is from a MERN stack course I completed on Udemy. I decided to take this course after learning the basics of ReactJS, to understand how the React frontend works with the Express backend. I added much of my own code to improve this app. The original app used local file storage to store the photos, I incorporated cloudinary to store the photos. I also implemented the use of JoiSchemas to validate data before adding to the database. I also incorporated much of my own error handling and code to remove user photos and other data from the DB when the user deleted the account. I enjoyed building this app, it was a great refresher on authentication and authorization. I learned more about mongoDB and mongoose. This course went really in depth into React functional componenents, so I learned a lot more about React including: React Router, ContextAPI, and reducer functions. I also had my first experience using JSON Web Tokens.
